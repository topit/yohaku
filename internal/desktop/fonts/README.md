# Bundled editor fonts

Unmodified Regular TrueType faces. All three are SIL Open Font License 1.1;
the complete copyright notices and licenses are in the adjacent `*-OFL.txt`.
Fonts are embedded for offline use, registered only when selected/previewed,
and not installed in the user's OS. CJK/emoji use MyGo's system fallback.
No Nerd Font icon payloads, extra weights or remote font services are included.
